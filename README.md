# chinmayrawat15.github.io

Academic homepage for Chinmay Rawat, served by GitHub Pages at https://chinmayrawat15.github.io/.

Plain static HTML on the AcademicPages / Minimal Mistakes stylesheet (MIT), no build step:

- `index.html` — the page: about, news, publications (Selected / All), projects, experience, honors, education
- `assets/css/main.css` — the compiled theme stylesheet; `publications.css` — the publication list; `custom.css` — small overrides
- `assets/js/publications.js` — the Selected / All tab switch
- `assets/fonts/` — Font Awesome 5 Free webfonts used by the sidebar icons
- `images/` — headshot and favicon; `files/` — CV and paper/poster PDFs

Preview locally with `python3 -m http.server 8080` and open http://localhost:8080/.
