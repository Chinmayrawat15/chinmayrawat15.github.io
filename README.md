# chinmayrawat15.github.io

Academic homepage for Chinmay Rawat, served by GitHub Pages at https://chinmayrawat15.github.io/.

Plain static HTML, no build step:

- `index.html` — the page (about, news, publications, research experience, projects, open source, honors)
- `assets/css/main.css`, `assets/js/main.js` — styles (light/dark) and a little JS (theme toggle, news fold, nav highlight)
- `images/` — headshot, favicon, thumbnails
- `files/` — CV and paper/poster PDFs

Preview locally with `python3 -m http.server 8080` and open http://localhost:8080/.
